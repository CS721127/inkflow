Welcome to Interactive Writer Pro
A quick guide — start typing to dismiss.

Write Markdown. Try # Heading, **bold**, - List, or use the formatting toolbar.

Preview & math. Use Edit / Split / Preview / ⛶ Fullscreen. Write inline $x^2$ or a standalone $$...$$ formula.

Improve your writing. Click ✨ Analyze for writing suggestions, or Check grammar for English spelling and grammar.

Export beautifully. Select a PDF Style, use 👁 Preview to browse stationery templates, then click 📄 PDF. You can also download a .md or .txt file.

Work with files. Open several local .md files, switch tabs, and export or restore a workspace. Click 💾 Save to save this workspace locally (auto-save is off by default).

Tip: Ctrl/Cmd + Space for Markdown suggestions. Grammar Check uses locally installed Harper; no document uploads. This guide is not part of your document.

Settings

Control how this writer saves your work.

Grammar Check uses local Harper files (installed once with npm install). Your writing stays on-device; Writing Analysis works without Harper. Save controls remain unchanged.

The Save button saves the entire open workspace to browser storage. Use ↓ Workspace to download a portable JSON backup. Clear → Clear storage deletes saved local data, without closing your current files.
