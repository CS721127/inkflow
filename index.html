Welcome to InkFlow
A quick guide to your workspace. Start typing to dismiss.

Write in Markdown. Try # Heading, **bold**, *italic*, - List, or - [ ] Task. Use the compact formatting toolbar above.

Edit and preview. Switch between Edit, Split and Preview, or open Fullscreen for distraction-free reading.

Equations. Type $x^2$ inline, or $$\int_0^1 x\,dx$$ as a standalone equation. Formulas appear in Preview and PDF exports.

Multiple files. Use New document or Open local files in the sidebar. Rename documents there and use Workspace tools to back up or restore all open documents.

Analyze writing. Click Analyze for clarity, style and structure feedback in the Dashboard. English Grammar Check uses locally installed Harper when available.

Export. Choose Source file to download .md or .txt. Choose PDF document to preview A4 pages, browse 12 stationery styles, then choose Download A4 PDF, or Print on desktop.

Privacy and saving. Save stores your workspace on this device. Auto-save is off by default and can be enabled in Settings. Clear can erase the current canvas or browser storage.

Ctrl/Cmd+B bold · Ctrl/Cmd+I italic · Ctrl/Cmd+Space Markdown suggestions · Ctrl/Cmd+S save. This guide is never part of your document.

Settings

Control how this writer saves your work.

Grammar Check uses local Harper files (installed once with npm install). Your writing stays on-device; Writing Analysis works without Harper. Save controls remain unchanged.

The Save button saves the entire open workspace to browser storage. Use Export workspace to download a portable JSON backup. Clear → Clear storage deletes saved local data, without closing your current files.

Quick guide

Write with Markdown headings, lists, tables and inline $math$ or display $$math$$.

Use Edit / Split / Preview, or Fullscreen for reading. Analyze opens the writing dashboard, with optional English grammar suggestions.

Save stores the workspace in this browser. Auto-save is off by default. Export .md / .txt or choose a PDF paper style from the gallery.
